# Codex Keypad — Domain glossary

- **Project:** the software project being represented or operated.
- **Task:** a Codex conversation or work unit.
- **Coordinator task:** a standing task that coordinates work for a project. The
  Blackbuild workflow calls this task a **Hive**; that name is optional product
  vocabulary.
- **Worker task:** a bounded task coordinated by a coordinator task.
- **Control surface:** a hardware interface that presents state and accepts user
  actions.
- **State source:** an adapter that observes Codex, GitHub, or another system and
  produces normalized state.
- **Handoff transport:** an interchangeable mechanism for moving normalized state
  and semantic actions across a process boundary.
- **Device adapter:** hardware-specific rendering, registration, and input
  handling.
- **Attention state:** a condition that may require a user's attention, such as
  approval, input, review, or failure.
