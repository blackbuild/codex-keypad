# Domain documentation

This repository uses a single domain context.

Before domain-sensitive exploration or design, read:

- `CONTEXT.md` at the repository root; and
- applicable accepted decisions under `docs/adr/`, when that directory exists.

Use the vocabulary defined in `CONTEXT.md` in issues, designs, tests, and code. If
a required concept is absent, first decide whether it is unnecessary terminology
or a genuine modeling gap.

If proposed work contradicts an accepted ADR, identify the conflict explicitly
instead of silently overriding the decision.
