# Feature triage

Use-case evidence helps prioritize enhancements and prevents a useful request
from growing into a kitchen-sink feature. Apply this policy when an enhancement
is newly triaged or revisited for another reason.

Record what available evidence supports:

- **Primary use case:** actor, task, and desired outcome justifying the smallest
  coherent feature.
- **Need horizon:** `immediate` for current work or `future` for an anticipated
  use.
- **Workaround:** whether an acceptable alternative already exists.
- **Secondary uses:** valuable but outside the minimum scope unless independently
  justified.

Missing fields should not automatically block triage. They influence confidence
and priority. A genuinely small improvement may use a concise quick-win rationale
when its behavior is obvious and it creates no meaningful compatibility,
maintenance, or architectural commitment.
