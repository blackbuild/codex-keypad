# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub Issues in
`blackbuild/codex-keypad`. Use the `gh` CLI for tracker operations and refresh
issue state before making recommendations or changes.

## Pull requests

Pull requests are implementation and review artifacts. They are not an incoming
request or triage surface for now. GitHub shares one number space across issues
and pull requests, so resolve ambiguous `#<number>` references before acting.

## Authority

Reading the tracker does not authorize mutation. Creating, editing, labelling, or
closing issues and publishing pull-request changes require the authority granted
for that repository and task. Local implementation completion does not imply that
an issue, pull request, or external delivery is complete.

When a skill says to publish to the issue tracker, create a GitHub Issue. When it
says to fetch the relevant ticket, read the issue body, labels, and comments.
