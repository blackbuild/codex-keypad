# Triage labels

The skills use five canonical triage roles. Map them to these GitHub label names:

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous work |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment is required |
| `wontfix` | `wontfix` | The request will not be actioned |

Use the mapped label whenever a skill refers to the corresponding role. Label
creation and other remote tracker changes remain separate authorized actions.
